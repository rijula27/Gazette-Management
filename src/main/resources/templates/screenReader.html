Screen Reader Access

Assistive technologies are meant to cater to the needs of people with various impairments like visual, hearing, mobility, and learning impairment. These technologies help differently-abled people in rendering or viewing a webpage. Screen readers convert text into synthesized speech, enabling visually impaired users to listen to and comprehend webpage content. Visit the following links to learn more:

  • http://www.screenreader.net
  • http://www.freedomscientific.com
  • http://www.gwmicro.com
  • http://www.spectronicsinoz.com

This website complies with W3C's Web Content Accessibility Guidelines (WCAG) 2.0 Level AA. It supports screen readers like JAWS (Job Access With Speech), NVDA (Non Visual Desktop Access), SAFA (Screen Access For All), Supernova, and Window-Eyes.
