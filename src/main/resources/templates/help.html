Accessibility Help

Use the accessibility options provided by this Website to control the screen display. These options allow increasing the text spacing, changing the text size and colour scheme for clear visibility and better readability.

Text Size Icons

  • Increase text size: Up to 3 levels
  • Decrease text size: Down to 3 levels
  • Reset to default text size

Changing the Colour Scheme

Change the color scheme for better visibility:

  • Default contrast scheme
  • Yellow text on Black background
  • Black text on White background

Note: Images are not affected by color changes.

Changing the Text Spacing

To improve readability for visually impaired users, increase spacing between letters.

Click to increase spacing and to reset to default.
