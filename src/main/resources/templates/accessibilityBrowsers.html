Accessibility Options in Browsers

Microsoft Internet Explorer for Windows

  • Go to Tools menu → Click Internet Options → Open the General tab → Click Accessibility
  • Tick the box that says: 'Ignore font sizes specified on Web pages'
  • Tick the box that says: 'Ignore colours specified on web pages'
  • To change text size: Click View menu → Select Text Size → Choose the size you prefer (e.g., Medium, Large)

Making Text Larger in Mozilla Firefox

  • Click on the View menu → Hover over Text Size → Choose your preferred size (or use keyboard shortcuts like Ctrl + + to zoom in, Ctrl + - to zoom out, and Ctrl + 0 to reset)
  • To always use a larger font size: Go to Tools → Click Options → Under Content tab, click Fonts & Colours → Click Advanced and set a minimum font size

Internet Explorer 7 and Above

  • Use keyboard shortcut Ctrl + + to zoom in, and Ctrl + - to zoom out
  • To change text size: Click on Page menu → Choose Text Size → Select the size you want
  • To force websites to ignore their own font sizes: Go to Tools → Select Internet Options → Click Accessibility → Check the option 'Ignore font sizes specified on Web pages'

Google Chrome

  • To zoom in (make everything bigger): Press Ctrl + +
  • To zoom out (make everything smaller): Press Ctrl + -
  • To reset zoom level to default: Press Ctrl + 0
