Accessibility Options in Browsers

Microsoft Internet Explorer for Windows

  • Tools → Internet Options → General Tab → Accessibility
  • Check: 'Ignore font sizes specified on Web pages'
  • Check: 'Ignore colours specified on web pages'
  • View → Text Size → Select desired size

Making Text Larger in Mozilla Firefox

  • View → Text Size → Choose your size (or use Ctrl + +/-/0)
  • To set a minimum font size: Tools → Options → Content → Fonts & Colours → Advanced

Internet Explorer 7 and above

  • Use Ctrl + + or - for zoom
  • Page → Text Size → Choose size
  • To override fixed-size sites: Tools → Internet Options → Accessibility → Check 'Ignore font sizes'

Google Chrome

  • Use Ctrl + + to zoom in
  • Ctrl + - to zoom out
  • Ctrl + 0 to reset to default size
